## First Local Validation Finding

The first direct run of:

```powershell
pwsh -NoProfile -File ./pw-git.ps1 refresh-structure
```

reached the standalone exporter but failed with:

```text
The property 'Count' cannot be found on this object.
```

Cause:

- PowerShell can unwrap a directory containing exactly one included child into a scalar object.
- `Write-Tree` assumed `Children` always remained an array and accessed `.Count` directly.
- `RefreshStructure.ps1` uses strict mode, exposing the invalid assumption.

Fix:

- Normalize recursive inputs with `@(...)` in model generation, statistics, and tree rendering.
- Evaluate child count through a normalized collection.
- Add an execution-level Pester fixture containing a directory with exactly one included child under strict mode.

The failure was in the exporter. The Pw-Git command routing correctly reached the intended script.
