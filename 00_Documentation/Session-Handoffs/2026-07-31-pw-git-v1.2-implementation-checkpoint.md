## Command-Parity Fix

The repository-root launcher now exposes the same commands as the modular dispatcher, including the previously omitted:

- `fetch`
- `stage`
- `review-staged`

Both launchers also expose:

- `refresh-structure`

`PwGit.Tests.ps1` parses both launcher `ValidateSet` declarations and compares their normalized command lists.

## Local Validation Sequence

From the repository root in PowerShell 7.6.4:

```powershell
git pull
pwsh -NoProfile -File ./pw-git.ps1 check
pwsh -NoProfile -File ./pw-git.ps1 fetch
pwsh -NoProfile -File ./pw-git.ps1 refresh-structure
Invoke-Pester ./10_Scripts/Tests/PwGit.Tests.ps1
```

Then verify interactively:

```powershell
pwsh -NoProfile -File ./pw-git.ps1
```

Interactive checks:

1. Press `H` to open Advanced operations.
2. Confirm option 7 is `Refresh repository structure`.
3. Run option 7.
4. Confirm both generated output paths are reported.
5. Confirm Git status is displayed.
6. Confirm the command returns to the Advanced menu.
7. Press `B` or Enter and confirm return to the main menu.
8. Confirm `Q` exits from either menu.

Direct-command parity checks:

```powershell
pwsh -NoProfile -File ./pw-git.ps1 fetch
pwsh -NoProfile -File ./pw-git.ps1 stage
pwsh -NoProfile -File ./pw-git.ps1 review-staged
pwsh -NoProfile -File ./pw-git.ps1 refresh-structure
```

`stage` and `review-staged` may report that no applicable changes exist; successful command acceptance is the parity check.
