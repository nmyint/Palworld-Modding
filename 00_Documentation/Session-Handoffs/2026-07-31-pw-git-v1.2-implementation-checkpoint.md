## Validation Findings and Fixes

### Scalar child collection

The first direct refresh reached the exporter and failed because PowerShell unwrapped a directory containing one included child into a scalar. Recursive values were normalized with `@(...)`, and a strict-mode single-child execution fixture was added.

### File record without Children

The next direct refresh failed because `Write-Tree` read `.Children` before verifying that the model record represented a directory. The exporter was corrected to access children only for directory records.

The failed run also demonstrated that generated-output replacement needed to be atomic. The exporter now:

- generates text and JSON through uniquely named temporary files;
- preserves backups of existing tracked outputs;
- replaces final outputs only after both temporary files are complete;
- restores prior outputs if replacement fails; and
- removes temporary and backup artifacts in `finally`.

Both failures were inside the standalone exporter. Pw-Git routing correctly reached `RefreshStructure.ps1`.
