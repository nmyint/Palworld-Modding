## Local Validation Finding 1

The first direct refresh reached the exporter and failed with:

```text
The property 'Count' cannot be found on this object.
```

Cause:

- PowerShell can unwrap a directory with one included child into a scalar.
- The exporter assumed the value always remained an array.

Fix:

- Normalize recursive values with `@(...)`.
- Add a strict-mode single-child execution fixture.

## Local Validation Finding 2

After the first fix, the direct refresh failed with:

```text
The property 'Children' cannot be found on this object.
```

Cause:

- `Write-Tree` read `.Children` before confirming that the model item represented a directory.
- File records intentionally do not define a `Children` property.
- The failed export had already started writing `RepositoryStructure.txt`, leaving the generated text map incomplete and causing the module-manifest freshness test to fail.

Fix:

- Read `.Children` only inside the directory branch.
- Generate text and JSON output in uniquely named temporary files.
- Preserve backups of existing tracked outputs before replacement.
- Restore both prior outputs if either final replacement fails.
- Remove temporary and backup artifacts in `finally`.
- Strengthen the execution test to verify text output, JSON output, one-child structure, replacement of stale files, and cleanup of temporary artifacts.

The failures were within the standalone exporter. Pw-Git routing correctly reached `RefreshStructure.ps1` in both cases.
