## Defects Found and Fixed

### Scalar child collection

PowerShell could unwrap a directory containing one included child into a scalar. Recursive values are now normalized with `@(...)`, with strict-mode regression coverage.

### File record without `Children`

`Write-Tree` previously accessed `.Children` before confirming that an item was a directory. Child access is now restricted to directory records.

### Partial generated output

A failed export could begin replacing one tracked output before the second output completed. The exporter now writes temporary files, preserves backups, replaces outputs only after successful generation, restores prior files on failure, and removes temporary artifacts in `finally`.
