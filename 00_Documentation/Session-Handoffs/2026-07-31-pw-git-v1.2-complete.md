## Exporter Fixes

Local validation found and fixed two strict-mode defects:

1. A single child could be unwrapped into a scalar, causing `.Count` access to fail.
2. `Write-Tree` read `.Children` on file records that intentionally do not define that property.

The exporter now normalizes recursive collections and writes both generated outputs through temporary files with backup and rollback handling.
