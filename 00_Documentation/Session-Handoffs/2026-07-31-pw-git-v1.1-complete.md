## Confirmed Decisions

- Pw-Git remains separate from PwWorkshop.
- Pw-Git remains a side-tooling project rather than a Workshop sprint.
- The main menu remains numbered 1–9.
- `H` opens Advanced operations; it is not a Help command.
- Repository history is available from Advanced option 5.
- `B` or Enter returns from the Advanced menu to the main menu.
- Main-menu option 9 pushes existing committed changes only.
- The direct `push` command retains its guided commit-and-push behavior.
- Staged-change review remains available through the direct `review-staged` command.
- Advanced destructive operations require confirmation.
- Discard excludes untracked files.
- Restore stash uses `git stash apply --index`, preserving the stash entry.
